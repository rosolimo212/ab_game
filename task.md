# Игра в A/B-тесты
Приложение в котором можно оценить "на глаз" поведение метрики в A/B-тесте, а потом сравнить с тем, что говорят стат-тесты. 

# Суть
Приложение в браузере (с использованеим технологии streamlit или похожей) генерирует временной ряд метрики по заранее заданным условиям (распределение, среднее, дисперсия и т.д.)

После этого строится график двух временных рядов. 

Пользователю предлагается угадать просто по графику, значимы различия или нет. За верные угадывания он получает бонусные баллы. 

В конце сессии пользователь видит свою общую оценку. 

# Технологии
Основной код - python
Логирование - постгрес
Интерфейс - streamlit
